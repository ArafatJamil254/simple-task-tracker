# Interactive To-Do List App (Taskflow)

A modern, responsive task management application built with semantic HTML5, CSS3, and Vanilla JavaScript with LocalStorage persistence.

## Features
- Add, complete, and delete tasks with instant UI updates
- Live progress bar and completion percentage indicator
- Filter tasks by status: All, Active, and Completed
- Full persistence across browser refreshes via LocalStorage
- Dark-mode responsive card layout

## Preview
Open `index.html` in your browser.
